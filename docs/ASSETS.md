# Asset provenance

Generation V Black/White animated sprites are copied from the PokeAPI sprites repository, with these National Pokédex IDs: Snivy 495, Tepig 498, Oshawott 501, Zorua 570, Chandelure 609.

Source pattern: https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/versions/generation-v/black-white/animated/495.gif

PNG files are first-frame format conversions used to pause the GIF animations. Pokémon characters and artwork belong to their respective rights holders; this is an unofficial personal theme.
